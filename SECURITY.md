# Security policy

This repository contains experimental kernel code. Do not load it on a system where a kernel crash or data loss would be unacceptable.

Please do not post security-sensitive information, raw audio, machine identifiers, disk UUIDs, logs containing personal paths, or credentials in public issues. For a suspected vulnerability, use GitHub's private vulnerability reporting for this repository if available; otherwise contact the maintainer through their GitHub profile.

Only the iMac18,2 with the listed codec and tested kernel has been functionally checked. There is no supported release or stability commitment.
