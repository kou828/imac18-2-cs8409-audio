# Security policy

This repository contains experimental kernel code. Do not load it on a system where a kernel crash or data loss would be unacceptable.

Please do not post security-sensitive information, raw audio, machine identifiers, disk UUIDs, logs containing personal paths, or credentials in public issues. For a suspected vulnerability, use this repository's GitHub private vulnerability reporting form. Do not report vulnerabilities in public issues.

Only the iMac18,2 with the listed codec and tested kernel has been functionally checked. There is no supported release or stability commitment.
