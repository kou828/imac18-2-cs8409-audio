# Contributing

This is a narrowly scoped, hardware-specific experiment. Before proposing changes:

1. State the exact iMac model, codec/subsystem ID, distribution, and kernel version.
2. Run `./check.sh` and build only against matching kernel headers.
3. Include the relevant output, with usernames, hostnames, disk UUIDs, serial numbers, network details, and personal paths removed. Never attach raw audio.
4. Do not submit or recommend a prebuilt kernel module for an unverified machine. Keep installation and recovery steps out of automated scripts unless they are separately reviewed.

By submitting code, you agree it may be distributed under this repository's GPL-2.0-only license.
